### 🚀 Featured Projects

<details>
<summary><b>⏱️ PulseWatch — Uptime Monitoring & Incident Platform</b></summary>
<br/>

Built a scalable, fault-tolerant uptime monitoring system in FastAPI and React, with an asynchronous probe engine, a distributed job scheduler, incident alerting, and LLM-assisted root-cause summaries.

| Aspect | Detail |
|---|---|
| **Stack** | FastAPI, Python, PostgreSQL, Asyncio, React.js, OpenRouter |
| **Monitoring** | 20 concurrent async probes over HTTP/TCP at 15-second intervals, with SSRF protection and SSL certificate monitoring |
| **Scheduling** | PostgreSQL row-level locking (`SELECT ... FOR UPDATE SKIP LOCKED`) with 30-second leases, ensuring 0% duplicate checks across horizontally scaled replicas |
| **Alerting** | Incident detection state machine (3 consecutive failures, 10-second re-probe) that cut 95% of false-positive alerts, with notifications delivered through REST webhooks to multiple channels |
| **AI** | Root-cause summaries from 5-stage HTTP telemetry in under 1.5 seconds via OpenRouter, backed by a 100% deterministic fallback |
| **Links** | [Live Demo](ADD_PULSEWATCH_DEMO_URL) · [Repository](https://github.com/Anup171/PulseWatch) |

</details>

<details>
<summary><b>🧩 Veritas AI — Autonomous Multi-Agent Research System</b></summary>
<br/>

Built a multi-agent AI research platform with LangGraph and LangChain, orchestrating four autonomous agents to plan research objectives and produce structured, cited reports.

| Aspect | Detail |
|---|---|
| **Stack** | Python, LangGraph, LangChain, Docker, Chainlit, Pydantic |
| **Research** | Plans 3–5 objectives and generates 8-section reports with APA and IEEE citations |
| **Credibility** | 0–100 source credibility scoring across 50+ trusted domains; filters sources below 40 and prioritizes high-authority data (70+) for conflict resolution |
| **Resilience** | 3-state circuit breaker (5-failure threshold, 30-second reset) and SQLite checkpointing, enabling 100% state recovery after process crashes |
| **Efficiency** | MD5-keyed caching layer (7-day TTL) that reduces redundant LLM calls; real-time token and cost monitoring; containerized with Docker |
| **Links** | [Live Demo](ADD_VERITAS_DEMO_URL) · [Repository](https://github.com/Anup171/Veritas-AI) |

</details>

<details>
<summary><b>🔔 NotifyX — Real-Time Notification Platform</b></summary>
<br/>

Built an event-driven, asynchronous notification service in Node.js and Express.js with idempotent delivery, WebSocket messaging, offline queue reconciliation, and a secured multi-tenant REST API.

| Aspect | Detail |
|---|---|
| **Stack** | Node.js, Express.js, Socket.IO, Redis, MongoDB, JWT |
| **Performance** | Uses `setImmediate` to decouple ingestion and return `202 Accepted` in under 5ms; real-time in-app delivery over WebSockets at sub-50ms latency |
| **Idempotency** | Two-tier deduplication with Redis `SETNX` (24-hour TTL) and a MongoDB unique index, preventing duplicate deliveries across network retries |
| **Delivery** | Offline queue reconciliation on reconnect; Redis cache-aside for unread counts |
| **Security & Limits** | SHA-256 hashed API keys; rate limiting of 10K requests/min globally and 50 requests/min per user; quiet-hour scheduling |
| **Links** | [Live Demo](ADD_NOTIFYX_DEMO_URL) · [Repository](https://github.com/Anup171/NotifyX) |

</details>
